OUR CHURCH & OUR VILLAGE WEBSITE — STARTER PACKAGE

CONTENTS
- index.html: complete single-page responsive website
- styles.css: custom design styles
- assets/: reserved for your approved church and village photographs

HOW TO OPEN
1. Extract this ZIP file on Windows or Mac.
2. Open the folder.
3. Double-click index.html. It opens in Chrome, Edge, Firefox or Safari.
4. On Android/iPhone, upload the folder to a web host (or copy it to a hosting service) and open the website link in the phone browser.
5. Internet is required for the Bootstrap and Google Fonts CDN resources. The page structure and custom CSS are local.

IMPORTANT BEFORE PUBLICATION
This is a first draft/template. Replace every [bracketed] item and the photo placeholders with verified, approved information:
- Parish Priest's approved name/message, church history, Mass timings and feast details
- Village history, school details and verified development priorities
- Official phone/email
- Official bank account and UPI/QR details, only after written/clear authorisation
- Verified income, expenditure and balance reports

Do not publish invented donation amounts, beneficiary names, personal medical details, private family details or unverified village statistics. Keep beneficiary information confidential. Have the Parish Priest / authorised committee approve donation handling, receipts, fund restrictions, public reporting and applicable legal/tax requirements before collecting donations.

The website currently does not process payments, store donor data, or send donation forms. It only displays the official donation instructions you add after verification.
